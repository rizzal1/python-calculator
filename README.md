# 🧮 Smart Python Calculator

Простой, но расширяемый калькулятор на Python с поддержкой основных арифметических и инженерных операций.

## 🚀 Возможности
- Сложение, вычитание, умножение, деление
- Возведение в степень и извлечение квадратного корня
- Обработка ошибок (деление на ноль, отрицательный корень)
- Чистый ООП-код

## 🛠️ Запуск проекта

```bash
python main.py
