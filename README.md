Универсальный консольный калькулятор на Python, написанный с соблюдением принципов ООП. Поддерживает как базовые арифметические действия, так и инженерные вычисления с обработкой исключений.

---

##  Основные возможности

-  **Базовая арифметика:** Сложение, вычитание, умножение и безопасное деление.
-  **Инженерные операции:** Возведение в степень ($a^b$) и извлечение квадратного корня ($\sqrt{x}$).
-  **Безопасность вычислений:** Встроенная обработка ошибок (деление на ноль, корень из отрицательного числа, невалидный ввод).
-  **Интерактивный CLI:** Удобный интерфейс командной строки с непрерывным циклом ввода.
-  **Чистая архитектура:** Выделенный класс-движок (`Calculator`) для легкого встраивания в другие сервисы.
